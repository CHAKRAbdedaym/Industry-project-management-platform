# Industry-project-management-platform

A microservices-based platform for managing industry projects, built as a monorepo.

## Services

| Service         | Status      | Description                                    |
|------------------|-------------|-------------------------------------------------|
| [`auth-service`](./auth-service) | in progress | User registration, login, and JWT issuance |
| `project-service`  | planned     | Project management                             |
| `task-service`     | planned     | Task management                                |
| `notification-service` | planned | Notifications                                  |
| `api-gateway`      | planned     | Single entry point routing to backend services |
| `frontend`         | planned     | Angular dashboard                              |

Each service is an independent module with its own README, build, and tests. See a service's README for setup instructions.
